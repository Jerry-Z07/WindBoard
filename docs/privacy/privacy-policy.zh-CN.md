# WindBoard（轻风白板）隐私政策

**生效日期：2026 年 9 月 19 日**
**最后更新：2026 年 9 月 19 日**
**政策版本：1.0**

本隐私政策适用于 Windows 桌面应用 **WindBoard（轻风白板）**（以下简称"本应用"），由开发者 **Jerry Z07**（以下简称"我们"）开发并发布。本政策适用于本应用通过任何渠道（包括 Microsoft Store 与 GitHub Releases）分发的所有版本，以及本应用发布的所有市场。

## 一、摘要

- 本应用**不需要注册账号**，也不要求你提供任何身份信息。
- 本应用**不收集、不上传你的个人信息**，不包含广告、行为分析或遥测组件。
- 你的白板内容、设置与诊断信息**只保存在你自己的设备上**，我们无法访问。
- 本应用仅在**更新检查/下载**与**你主动指定的网络地址**这两类功能中访问网络。

## 二、我们不会收集的信息

本应用不会收集、存储或向我们传输以下任何信息：

- 姓名、邮箱、电话号码、通讯地址等身份识别信息；
- 设备位置数据；
- 摄像头、麦克风、通讯录、短信等隐私数据（本应用未申请相应系统能力）；
- 使用行为统计、功能点击埋点、设备标识符或广告标识符；
- 你的笔迹、白板内容、导入的图片或导出的文件（这些内容仅在你主动导出时写入你选择的位置）。

本应用仅在以下情况下读取本地文件：你在文件选择器中主动选择文件（导入 WBIX/WBI/图片）、你为 Dock 快捷方式或伪装功能指定本地路径时。除此之外，本应用不会扫描或读取与功能无关的文件。

## 三、仅保存在你设备上的数据

本应用会在本机保存运行所需的数据，用于提供功能与排查问题。这些数据**不会自动上传**：

| 位置 | 内容 | 用途 |
| --- | --- | --- |
| `settings.json` | 界面与书写偏好、Dock 快捷方式条目（含你填写的链接地址与本地路径）、更新与伪装偏好等设置 | 记住你的自定义配置 |
| `Logs\` | 运行日志 | 运行状态记录与故障排查 |
| `Logs\Crashes\` | 崩溃报告（异常类型与堆栈、应用版本、进程 ID、处理器架构、.NET 与 Windows 版本、安装形态及相关目录路径） | 崩溃原因定位 |
| `camouflage\` | 你为伪装功能选择的图标文件副本 | 应用自定义外观 |
| `downloads\` | 更新包下载缓存 | 避免重复下载 |
| 你指定的位置 | 你主动导出的工作区文件（`.wbix`）、PNG/PDF 图片，以及你导入的文件 | 由你完全掌控 |

存储位置说明：

- **Microsoft Store（MSIX）版与非商店安装版**：数据位于 `%LocalAppData%\WindBoard`（MSIX 版由 Windows 系统重定向到应用包私有存储）；
- **便携版**：数据位于程序目录下的 `data\`；若该目录不可写，则回退到 `%LocalAppData%\WindBoard`。

你可以随时自行查看、复制或删除上述文件。崩溃报告与日志由你决定是否提供给开发者，本应用不会自动发送。

## 四、本应用何时会访问网络

本应用的所有网络请求均使用 HTTPS，且**不包含任何可识别你身份的凭据或标识符**（请求头中的 `User-Agent` 仅包含应用名称与版本号，例如 `WindBoard/1.2.3`）。

| 场景 | 目标服务 | 触发条件 | 发送内容 |
| --- | --- | --- | --- |
| 检查更新 | `github.com`（WindBoard 仓库的 Release 元数据） | 由你手动触发，或按你的设置在启动后自动检查（可在设置中将"自动检查更新"设为"从不"） | 应用名称与版本的请求头，不含个人数据 |
| 下载更新包 | `github.com` 或镜像加速服务 | 你确认下载更新时 | 同上 |
| 下载源测速 | 同上 | 你在设置中手动执行下载源测速时（已停发的旧安装版形态曾在首次运行时自动执行一次） | 同上 |
| 获取 Dock 链接图标 | 你在 Dock 中填写的网址所在站点 | 你添加"链接"类型的 Dock 快捷方式，或应用重新加载 Dock（例如启动）时 | 该站点的首页及图标地址请求 |
| 打开外部链接 | 系统默认浏览器 | 你点击应用内的链接（如 GitHub 发布页、Microsoft Store 页面）时 | 由浏览器按自身策略处理 |

说明：

- **Microsoft Store 版**的更新由 Microsoft Store 托管，应用内不会向 GitHub 发起更新检查或下载请求。
- Dock 链接图标属于可选增强功能：若你从不添加"链接"类型的快捷方式，本应用不会请求任何第三方网站。

## 五、第三方服务与数据共享

- 我们**不会**出售、出租或以任何方式向第三方共享你的个人信息，因为我们并不持有这些信息。
- **GitHub**：更新检查与更新包下载由 GitHub（GitHub, Inc.）提供。作为服务提供方，GitHub 可能记录你的 IP 地址与请求日志，这些日志由 GitHub 依其自身隐私政策处理，我们不参与也**无法访问**。
- **镜像加速服务**：当直连 GitHub 受限时，本应用可能通过第三方镜像（`gh-proxy.top`、`ghm.078465.xyz`）下载更新包。这些镜像由独立第三方运营，其同样可能记录访问日志；若你不希望使用，可在设置中固定使用 GitHub 官方源。
- **Microsoft Store**：通过 Microsoft Store 获取本应用时，安装、更新与许可由 Microsoft 处理，适用 Microsoft 自身的隐私政策。

## 六、数据安全

- 本应用不收集也不反向传输你的数据，因此不存在服务端的数据存储风险。
- 本机数据保存在当前 Windows 用户账户的权限范围内，由操作系统的账户与文件权限机制保护。
- 所有网络请求均通过 HTTPS 传输。

## 七、数据保留、删除与你的控制权

- **关闭联网功能**：可在设置中将"自动检查更新"设为"从不"，此后本应用不会再自动发起更新检查请求（手动触发"检查更新"时仍需联网）。
- **查看与删除本地数据**：直接打开上述数据目录即可查看或删除；删除 `%LocalAppData%\WindBoard` 目录（便携版为程序目录下的 `data\`）将清除全部本地数据。
- **卸载**：卸载本应用后，Microsoft Store 版本会由系统一并移除其包内私有数据；便携版删除程序目录即可。
- **反馈信息**：当你通过 GitHub Issues 提供日志或崩溃报告时，相关内容的处理遵循你在提交时自愿披露的范围，你可以随时要求删除该 Issue 中的内容。

## 八、儿童隐私

本应用不面向儿童收集任何个人信息，也不会有意收集 13 岁以下儿童的数据。由于本应用不收集任何个人信息，家长可以放心使用。

## 九、政策变更

- 当本应用新增或调整涉及数据处理的功能时，我们会同步更新本政策，并修改文首的"最后更新"日期。
- 重大变更会通过应用内提示或 Release 说明告知你。继续使用本应用即表示你接受更新后的政策。

## 十、适用范围

本政策适用于本应用及其全部市场版本。Microsoft 的隐私政策不适用于本应用；Microsoft 亦不为本应用提供默认隐私政策。

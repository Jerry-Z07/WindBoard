# 快速上手

本文主要介绍最常用的白板操作

## 界面速览

![intro](../images/Intro.png)

- ①：控制区 Dock
- ②：画笔设置面板
- ③：主 Dock
- ④：页面管理 Dock

## 书写与画笔设置

- 点击 **书写** 进入书写模式。
- 再次点击 **书写** 会弹出「画笔设置」，可更改画笔粗细和颜色
- 支持触控、手写笔、鼠标。

## 擦除与滑动清屏

- 点击 **擦除** 进入橡皮擦模式。
- 再次点击 **擦除** 会弹出「清屏滑块」，向右滑到底即可清屏

## 选择与编辑（笔迹 / 附件）

- 点击 **选择** 进入选择模式。
- 笔迹选择：选中笔迹后，会出现悬浮 Dock（置顶/复制/删除）。
- 附件选择：在选择模式下点击附件卡片即可选中，出现选中框与缩放手柄。
  - **拖动**选中框可移动
  - **拖动手柄**可调整尺寸
  - 悬浮 Dock 的 **复制** 目前仅对笔迹生效，附件不支持复制

## 撤销 / 恢复

- 点击底部工具栏的 **撤销 / 恢复**。

## 缩放与平移

- 鼠标滚轮：以光标所在位置为中心缩放。
- 鼠标右键拖动：平移画布视图。
- 触控：双指缩放/平移（可在设置中限制为“仅双指手势”）。

## 多页面

- 右下角分页控制条：
  - **上一页 / 下一页**
  - **新增页**
  - 点击页码/指示器：打开页面列表并进行切换/删除

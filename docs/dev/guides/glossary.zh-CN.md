# 术语表（Glossary）

界面文案里同一个东西只用这里的一个中文名和它对应的英文名。按钮、标题、提示、报错、无障碍标签都按这张表写；新增概念先在表里加一行，再写文案和测试。

## 规则

- 一个概念一个名字。同义词不进界面，最多出现在文档里。
- 借词保留原文：Dock、PNG、PDF、WBIX、DIP、Ctrl、Store。中文不写成「停靠栏」「快捷栏」。
- 中文界面动词用双字（见动作表）；英文用不带主语的祈使句（`Add page`、`Open log folder`）。
- 名称不随句式变形：换成占位符后名称保持不变，「删除页面」不会写成「删除该页面」。
- 中文用「目录」还是「文件夹」，看位置归属：应用自己的位置用目录，用户浏览的目标用文件夹。英文两者都是 folder。

## 对象

| 中文 | 英文 | 指什么 | 不要写成 |
|---|---|---|---|
| 画布 | canvas | 笔迹与元素所在的表面 | 白板、画板、board |
| 页 / 页面 | page | 连排与计数用「页」（上一页、下一页、当前页、页码、第 N 页）；当作对象用「页面」（添加页面、删除页面、页面管理、页面数量） | 上一页面、添加页 |
| 工作区 | workspace | 全部页面的集合；导入替换与 WBIX 覆盖的范围 | 文档、工程 |
| 笔迹 | stroke | 手写线条，擦除与旋转的对象 | 笔划、笔画、线条 |
| 形状 | shapes | 形状工具组；单个图形用具体名字（矩形、椭圆、直线、箭头） | 图形 |
| 元素 | element | 导入的图片、文件、文本、链接 | 附件、素材 |
| 元素卡片 | element card | 元素在画布上的卡片外观 | 元素卡、缩略图 |
| 资源 | resource | 元素引用的内嵌文件（图片、音频、视频） | 附件、素材 |
| Dock | Dock | 主界面底部与两侧的按钮条；设置里写「Dock 设置」 | 快捷栏、停靠栏、工具栏 |
| 快捷入口 | shortcut | Dock 上用户添加的条目 | 快捷方式、书签、收藏（这三个词留给桌面快捷方式等其它概念） |
| 桌面快捷方式 | desktop shortcut | 伪装功能写到桌面的 .lnk 文件 | 快捷方式（不带「桌面」） |
| 色板 | palette | 固定的一组颜色 | 调色板、颜色板 |
| 色块 | swatch | 色板里的一格 | 颜色格、槽位 |
| 滑条 | slider | 连续调节画笔粗细的控件 | 滑块、拖动条 |
| 粗细档位 | preset | 粗细的三档固定值（档位 1、2、3）；调节方式分「档位」与「滑条」 | 预设、挡位 |
| 留白 | padding | 导出 PNG、PDF 时内容四周的空白 | 边距、外边距 |
| 擦除模式 | eraser mode | 点擦与笔迹擦两档 | 橡皮模式 |
| 页码 | page number | 页的序号 | 页数 |
| 页数 | page count | 页的总数（WBIX 信息里的「页数」） | 页码 |
| 撤销 / 重做 | undo / redo | 操作历史的前后移动 | 撤消、恢复 |
| 备份 | backup | 用户主动导出的 WBIX 文件 | 存档 |
| 自动存档 | autosave | 网页端定时写入浏览器本地的副本 | 缓存、备份 |
| 压缩包 | archive | 元素卡片里的文件种类 | 归档 |
| 日志 | log | 诊断输出文件；所在位置写「日志目录」 | 记录 |
| 数据目录 | data folder | 应用保存设置与数据的位置 | 数据文件夹 |

## 位置与文件

| 中文 | 英文 | 用在哪里 |
|---|---|---|
| 目录 | folder | 日志目录、数据目录、设置目录（应用自己的位置） |
| 文件夹 | folder | 导出文件夹、下载文件夹（用户浏览的目标） |
| 子文件夹 | subfolder | 多页 PNG 的存放位置 |
| 路径 | path | 快捷入口的目标；「复制日志目录路径」 |

## 校验

- 桌面：`WindBoard.Tests/Localization/TerminologyAuditTests.cs` 读 `WindBoard/Strings/**/*.resw`。
- 网页：`web/tests/unit/terminology.test.ts` 读 `web/src/i18n/web-strings/*.json`。
- 中文里出现表里的禁用写法，或同一 key 的中英文没有用表里的一对名字，测试失败。
- 改术语的顺序：先改本表，再改文案，最后补或改测试。

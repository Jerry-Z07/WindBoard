# Changelog (v2.6.0)

- Added settings import, export, and restore features
- Fixed an issue where the screen annotation floating toolbar could be clipped under high DPI scaling
- Removed the settings migration on first launch for the portable edition
- Updated icons for some settings items

# Known Issues

- Users upgrading directly from v1.x by overwriting the installation may encounter unknown compatibility issues. It is recommended to completely uninstall the old version and reinstall the new one.

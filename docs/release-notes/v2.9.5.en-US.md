# Release Notes (v2.9.5)

> This is a transitional release: the installer-based distribution will be adjusted. Back up your settings first so you can import them after migrating — the notice at the top of the Settings window links straight to the backup entry.

- ✨ feat: Added shape drawing with line, rectangle, ellipse, and arrow shapes on both the main board and the screen annotation toolbar; a shape can be selected and its length, angle, width, and height adjusted precisely.
- ✨ feat: Upgraded the board file format (WBIX) to v3 so shapes can be saved and opened; files from v1/v2 still open normally.
- ✨ feat: Added a dismissible notice bar at the top of the Settings window that explains the distribution change and offers a "Back up settings" action.
- ✨ feat: Unified the visual language and sizing of the screen annotation toolbar to match the main board dock.
- ✨ feat: Replaced the update result dialog with the native system dialog and removed a third-party UI dependency.
- 🐛 fix: Fixed the export flow misreporting the chosen save location as overwriting an existing file.
- 🐛 fix: Fixed shape preview ghosting on the transparent canvas during screen annotation, and cases where shapes were not rendered at all.
- 🐛 fix: Fixed shape tool buttons being left out of dock reordering, which could make the entry disappear.

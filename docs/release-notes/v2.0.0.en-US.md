## Changes (v2.0.0)

### Highlights
- A brand-new ink engine with improved rendering performance.
- Refreshed UI, closer to the Windows 11 look and feel.

### Known issues
- For users on v1.x, installing over the existing version may cause unknown compatibility issues. It is recommended to completely uninstall the old version and reinstall.
- Some UI designs are not yet consistent.
- The new updater currently does not support rendering Markdown text.

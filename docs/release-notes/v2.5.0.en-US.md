# Changelog (v2.5.0)

- Added screen annotation : color selection, thickness adjustment, eraser mode switching, slide-to-clear canvas, and synchronized drawing state
- Redesigned the update result dialog, added Markdown changelog rendering, and improved how download options are presented
- Reduced high-noise logs to improve diagnostics

# Known Issues

- Users upgrading directly from v1.x by overwriting the installation may encounter unknown compatibility issues. It is recommended to completely uninstall the old version and reinstall the new one.

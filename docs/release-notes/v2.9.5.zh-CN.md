# 更新内容（v2.9.5）

> 这是一次过渡版本：安装版（安装包）的分发方式将调整。建议先备份设置，以便迁移后导入——设置窗口顶部的提醒可直接进入备份入口。

- ✨ feat: 新增形状绘制：直线、矩形、椭圆、箭头四种形状，主白板与屏幕批注均可使用，并可用选择工具选中后精确调整长度、角度、宽度与高度。
- ✨ feat: 白板文件格式（WBIX）升级到 v3 以承载形状，v1/v2 的旧文件仍可正常打开。
- ✨ feat: 设置窗口顶部新增可关闭的提醒区，用于提示安装方式调整，并提供「去备份设置」入口。
- ✨ feat: 统一屏幕批注工具条的视觉语言与尺寸，与主白板 Dock 保持一致。
- ✨ feat: 更新结果弹窗改用系统原生对话框，移除第三方 UI 依赖。
- 🐛 fix: 修复导出时选择保存位置被误判为「覆盖已有文件」的问题。
- 🐛 fix: 修复屏幕批注中透明画布上的形状预览残影，以及部分场景下形状不显示的问题。
- 🐛 fix: 修复形状工具按钮未参与 Dock 自定义排序、导致入口丢失的问题。

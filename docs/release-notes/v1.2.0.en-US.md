## WindBoard v1.2.0 Changelog
- Improved the InkV2 ink engine based on DX rendering, enhancing the operational smoothness when handling a large number of pen strokes.
- Improved the packaging workflow.
- Fixed the blur issue in the middle area Dock.

## Note for Users
Users who previously downloaded the portable version without the built-in runtime library are advised to switch to the version that includes the runtime library(Download it at https://github.com/Jerry-Z07/WindBoard/releases/latest). The portable version without the built-in runtime library will no longer be provided going forward.

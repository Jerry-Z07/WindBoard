# Release Notes (Web v2.11.0)

- ✨ feat: [Web] Added a web client (`web/`): a static, local-first PWA with pen, eraser, shapes, selection, and multi-page support. It opens and saves `.wbix` files interchangeably with the desktop app, and supports PNG/PDF/WBIX export, WBIX import, and settings file import/export.
- ✨ feat: [Web] The web client autosaves and recovers work, can be installed to the desktop or home screen, and works offline. It uses the WinUI 3 visual system, follows the configured or system language and theme, and adapts to narrow phone screens and safe areas.

## Changelog (v2.2.0)
- Updated the icon font
- Refactored the Import and Settings windows
- Fixed: The window cannot be minimized via the minimize button when in full-screen mode
- Fixed: The update progress popup cannot be displayed and the update interruption mechanism

- Extended the definition of WBIX files

## Known Issues
- Users upgrading directly from v1.x by overwriting the installation may encounter unknown compatibility issues. It is recommended to completely uninstall the old version and reinstall the new one.
- The new update program does not currently support rendering Markdown text.

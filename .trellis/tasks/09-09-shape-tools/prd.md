# 阶段二：图形绘制工具（直线/矩形/椭圆/圆/箭头）

> 父任务：`09-09-shape-drawing`（需求全集与决策见其 `prd.md`，需求编号 R5-R8 由父任务定义）

## Goal

在阶段一可插拔地基（`09-09-drawing-foundation`）上交付四种两点式形状工具与属性面板，主白板与屏幕批注层同步接入，形状可持久化、可导出、可撤销。

## 依赖约束（硬性）

- **必须先完成 `09-09-drawing-foundation` 合入**：本任务的形状实现、工具注册、序列化、渲染均依赖阶段一的抽象与注册点；阶段一未合入前本任务不得开始实施。
- 形状通过阶段一的注册机制接入，禁止引入新的散落式 if/else 分发（父任务跨验收第 2 条）。

## Requirements

- R5 形状工具（4 种，全部两点式手势：按下定起点、拖动定终点、释放提交）：
  - 直线、矩形、椭圆/圆、箭头（箭头 = 直线 + 端点箭头头部）
  - 绘制过程实时预览，释放后经命令栈提交
  - Shift 约束（正方/正圆/水平垂直线）为可选增强，进 MVP 后可后置
  - 主白板与屏幕批注层两层工具栏均提供入口
- R6 编辑语义：橡皮碰到形状 → 整笔删除；形状使用当前画笔颜色与线宽（ToolOptions）；不支持压感；无半透明描边。
- R7 持久化：形状随 WBIX v3 保存/加载往返一致；导出 PNG/PDF 正确渲染形状；旧版本文件无形状数据正常读取。
- R8 属性面板：选中单个形状后弹出属性浮层，按形状类型显示可编辑字段（直线/箭头=长度+角度；矩形=宽+高；椭圆/圆=宽+高/半径），数值输入经命令栈提交可撤销；面板机制对后续功能（函数绘制）可复用。

## UX 概览

```
主白板工具栏                        屏幕批注工具栏
[笔][荧光][橡皮][形状▾][选择]       [笔][橡皮][形状▾][...]
              │
              ▼ Flyout：直线 矩形 椭圆 箭头
   ┌──────────────────────────┐      ┌──────────────┐
   │  画布                     │      │ 属性浮层       │
   │   ╔══════╗ ←选中态(控制框) │      │ 宽  [320] px │
   │   ╚══════╝                │      │ 高  [180] px │
   │                           │      │ 线宽 [3.0]   │
   └──────────────────────────┘      └──────────────┘
```

## Acceptance Criteria

- [ ] 每种形状：拖拽绘制 → 预览正确 → 释放提交 → `Ctrl+Z` 撤销 → `Ctrl+Y` 重做，行为正确。
- [ ] 选中形状 → 属性面板出现且字段随类型变化 → 修改数值 → 画布实时更新 → 撤销恢复。
- [ ] 形状随当前画笔颜色/线宽变化；橡皮在形状上滑动 → 该形状整笔删除；橡皮对折线笔迹行为不变。
- [ ] WBIX 往返：含形状文档保存 → 重新打开 → 形状类型/几何/颜色/线宽一致；v2 旧文件仍可打开。
- [ ] 导出 PNG/PDF：形状正确渲染（与画布一致）。
- [ ] 屏幕批注层：四种形状可用，属性（颜色/线宽）与主白板独立或按现有批注参数体系正确联动。
- [ ] 单点注册复核：新增上述形状未在渲染器/序列化/命中处添加跨类型 if/else（均走阶段一注册点）。
- [ ] `dotnet test WindBoard.slnx` 全量通过，新增形状的域模型/命令/序列化有对应单测。

## Out of Scope

- 贝塞尔曲线（二期）、函数绘制（后续任务）、网格吸附/参考线、半透明描边、形状填充色、多形状组合/布尔运算
- 元素（文本/图片等）的属性面板复用（本阶段面板仅服务形状）

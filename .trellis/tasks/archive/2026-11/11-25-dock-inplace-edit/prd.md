# Dock 栏就地编辑：拖动排序、隐藏恢复与快捷入口增删改

## Goal

把 Dock 布局编辑从独立设置页迁移到主界面：从精简设置页进入编辑模式后，直接在 Dock 原位拖动排序、隐藏/恢复内置项、增删改快捷入口；独立设置页退化为“编辑入口 + 恢复默认”的精简页。

成功的判定：用户不离开主界面即可完成 Dock 布局调整，Dock 在所有分组上支持鼠标/触摸/笔拖动排序，隐藏项可原位恢复，快捷入口可增删改；重启与导入设置后布局保持。

## 范围（In Scope）

1. **编辑模式**：从精简设置页的“编辑 Dock”卡片进入；主窗口内全屏遮罩 + 同位置编辑层；工具栏提供完成、重置、快捷入口显隐与操作提示；Esc 退出。
2. **排序**：四组内置项（左、工具、撤销/重做、页面）支持拖动排序；键盘 `Ctrl+←/→` 可移动选中项；顺序写入现有四个 `*Order` 字段。
3. **隐藏/恢复**：内置项（`more` 除外）可在编辑层隐藏与恢复；隐藏项保留在顺序中，恢复后回到原位置；隐藏状态写入 `dock.hiddenItems`。
4. **快捷入口**：编辑层左右两侧显示快捷入口编辑区与“+”入口；支持添加文件/链接/程序、删除、编辑（路径、显示名、图标、参数、类型）、同侧拖动排序、跨侧拖动、从资源管理器/浏览器拖入文件或网址；上限仍为 5 个。
5. **精简设置页**：`DockSettingsPage` 只保留“编辑 Dock”与“恢复默认布局”；移除预览、排序列表、显隐开关与快捷入口编辑表单。
6. **应用器**：正常 Dock 不渲染隐藏项；整组隐藏时隐藏对应底板与分隔线；撤销/重做分隔线随可见项变化。
7. **跨端同步**：设置模型、归一化、快照、克隆、默认值语料与网页端 `model/settings-file/DockBar/DockPage` 同步 `hiddenItems`；网页端 Dock 页只留入口，主界面 `DockEditOverlay` 同步拖动、隐藏/恢复与重置（网页端 v1 无快捷入口 Dock）。
8. **测试与门禁**：桌面单测、E2E 更新、零告警构建；网页端 `pnpm verify`、`pnpm i18n` 与必要的 `pnpm e2e`。

## 非目标（Out of Scope）

- 网页端同步主界面就地编辑；但 v1 仍不实现快捷入口 Dock（浏览器无法启动外部程序），也不做快捷入口增删改。
- 内置项不跨组拖动（四组结构固定）；不新增“自定义内置按钮”或插件式 Dock 项。
- 快捷入口上限仍为 5；不实现快捷入口分组、子菜单或云同步。
- 不为 Dock 布局变更提供撤销/重做；重置有确认弹窗。
- 不改变 Dock 既有视觉规格（60×52 项、14 圆角、0.85 底板、浅色主题、间距）。
- 不新增设置 schema 版本号；`hiddenItems` 为向后兼容的附加字段。

## 交互规则

### 进入与退出

- 设置 → 外观 → Dock 设置 → “编辑 Dock”卡片进入：关闭设置窗口并在主窗口进入编辑模式；主窗口最小化时先恢复。“更多”菜单不新增 Dock 编辑入口。
- 进入后真实 Dock 隐藏，同位置显示编辑层；编辑层铺满内容区并拦截画布输入。
- 工具栏位于 Dock 上方：完成、重置、快捷入口开关、操作提示。
- “完成”或 Esc 退出；退出前已即时落盘，退出后真实 Dock 按最新设置重绘。

### 拖动排序

- 四组内置项均支持鼠标、触摸、笔拖动；拖动期间显示系统拖动视觉。
- 选中项后 `Ctrl+←/→` 可移动；移动后焦点跟随该项。
- 顺序持久化到 `leftOrder/toolsOrder/undoRedoOrder/pagesOrder`；隐藏项也参与排序。

### 隐藏与恢复

- 每个内置项右上角显示“隐藏”按钮；已隐藏项在编辑层以降低透明度 + 虚线边框呈现，按钮变为“恢复”。
- `more` 不显示隐藏按钮，悬停提示“更多是设置入口，不能隐藏”。
- 正常 Dock 不渲染隐藏项；某组全部隐藏时隐藏该组底板/分隔线；撤销/重做分隔线在两组均无可见项时隐藏。
- 隐藏项在重启、导入设置后保持隐藏。

### 快捷入口

- 编辑层左右两侧各有一个快捷入口编辑区与“+”入口；正常 Dock 即使未显示快捷区，编辑层也显示，便于首次添加。
- “+”菜单：文件、链接、程序。文件与程序使用系统文件选择器；链接弹出输入框并校验 `http/https`。
- 点击快捷项打开编辑对话框：类型、路径/网址、显示名称、图标来源（默认/自定义文件/图标字体）、启动参数；保存后立即落盘。
- 右上角“×”删除；删除不弹确认。
- 同侧内可拖动排序；拖到另一侧即改变 `Side`，落到目标侧末尾。
- 从资源管理器/浏览器拖入文件、文件夹或网址到某一侧：追加为快捷入口；文件/文件夹映射 `file`，网址映射 `link`。
- 两侧合计上限 5；达到上限时“+”禁用并提示。
- 新增第一个快捷项时自动把 `isShortcutDocksVisible` 置为 `true`。

### 工具栏开关

- 快捷入口开关：写 `isShortcutDocksVisible`，只影响正常 Dock；编辑层始终显示快捷编辑区。
- 撤销/重做不设整组开关：逐条隐藏 `undo`/`redo`，两项都隐藏时整组与分隔线消失（`isUndoRedoVisible` 字段已移除）。

### 精简设置页

- 仅两张卡片：
  - “编辑 Dock”：关闭设置窗口并进入主窗口编辑模式。
  - “恢复默认布局”：确认后 `Dock = new DockSettings()`（顺序、隐藏项、快捷入口显隐开关、快捷入口全部恢复默认）。
- 设置搜索仍能定位到 Dock 页；搜索锚点指向“编辑 Dock”卡片。

## 约束

- 平台：Windows App SDK / WinUI 3；禁止预发布依赖；不引入第三方拖拽库。
- 官方拖拽契约：`ListView` 内置重排必须同时设置 `AllowDrop=true`、`CanReorderItems=true`、`CanDragItems=true`；跨列表移动使用自定义 `DataPackage`（WinUI Gallery ListView 示例同款做法）。
- 设置：`hiddenItems` 只接受四个内置组内的 id；`more` 永不进入隐藏集合；去重、过滤未知项；旧设置文件缺字段时为空列表。
- 跨端：设置文件字段名 camelCase `hiddenItems`；桌面与网页端的归一化行为一致；默认值语料必须同步。
- 文案：只放在 `WindBoard/Strings/**/*.resw`（zh-CN/en-US）；C#/XAML 不写死中文界面文案；新增 key 后重新生成网页词表。
- 视觉：Dock 固定浅色主题；编辑层复用现有 Dock 尺寸与圆角常量。
- 可访问性：编辑层可 Tab 聚焦、`Ctrl+←/→` 排序、Esc 退出；隐藏/恢复/添加按钮有 `AutomationProperties.Name`；关键控件有稳定 `AutomationId`。
- 编辑期不应用 Dock 设置到真实 Dock，退出时统一应用，避免重建与拖动竞争。

## 风险与未决项

- WinUI 3 `ListView` 跨列表拖动与内置重排可能冲突；先按官方示例实现，实机验证失败则在编辑项上补“移到左侧/右侧”按钮作为兜底，不阻塞 AC4 的其余部分。
- 编辑层与真实 Dock 的视觉漂移：共用尺寸/颜色常量，E2E 截图复核。
- 隐藏 `more` 会锁死设置入口：归一化与 UI 双重禁止。
- 设置变更触发真实 Dock 重建：编辑期跳过应用，退出时统一应用。
